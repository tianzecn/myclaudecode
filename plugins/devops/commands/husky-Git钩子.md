# 仓库健康验证协议

此命令概述了验证和维护仓库健康状况的综合协议。

## 关键目标
- 验证仓库处于工作状态
- 运行 CI 检查
- 修复任何已识别的问题
- 准备暂存文件

## 主要步骤
1. 使用 `pnpm i` 更新依赖项
2. 运行代码检查器检查
3. 验证构建和类型
4. 运行测试覆盖率
5. 排序 package.json
6. 检查包
7. 再次检查所有前面的步骤
8. 暂存文件（避免 Git 子模块）

## 错误处理协议
1. 解释为什么出现问题
2. 提出并实施修复方案
3. 检查其他地方是否存在类似问题
4. 清理调试代码

## 重要指南
- 永远不要提交，只暂存文件
- 逐个包运行测试
- 愿意进行必要的修复
- 使用 TypeScript 和测试作为保护措施

本文档强调通过系统化的方法来维护代码质量和解决问题。
