# Git 工作树命令

本文档提供了两个用于 Git 工作树管理的主要 bash 脚本：

## 1. 为所有开放的 PR 创建工作树
- 使用 GitHub CLI 获取开放的拉取请求
- 为每个 PR 分支创建 Git 工作树
- 处理包含斜杠的分支名称
- 包含清理过时工作树的可选脚本

## 2. 交互式分支和工作树创建
- 提示输入新分支名称
- 验证分支名称
- 在 `./tree/` 目录中创建工作树
- 支持从不同的基础提交创建分支

## 主要特性
- 错误处理
- 目录管理
- 灵活的分支创建选项
- 通过使分支和工作树管理更高效来简化 Git 工作流程
