# 创建拉取请求命令

此命令自动化创建拉取请求的流程，具有以下关键特性：

## 主要行为
- 从当前变更创建新分支
- 使用 Biome 格式化文件
- 自动将变更拆分为符合逻辑的提交
- 生成描述性的提交消息
- 推送分支到远程仓库
- 创建包含摘要和测试计划的拉取请求

## 提交拆分指南
- 按功能、组件或关注点拆分提交
- 将相关文件变更放在一起
- 将重构与新功能分开
- 确保每个提交都能独立理解
- 将无关变更分离到不同的提交

该命令旨在通过提供智能的提交和拉取请求创建来简化代码贡献流程。
