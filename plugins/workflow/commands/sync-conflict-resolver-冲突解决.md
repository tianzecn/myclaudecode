# Sync Conflict Resolver - 冲突解决器

使用智能自动化解决同步冲突: **$ARGUMENTS**

## 当前冲突状态

- 同步数据库: @.sync-state.json 或包含潜在冲突的同步状态文件
- 冲突历史: !`find . -name "*conflict*" -o -name "*sync-errors*" | wc -l` 个冲突日志
- 解决规则: @conflict-rules.json 或现有解决配置
- 活跃冲突: 需要注意的当前未解决同步冲突

## 任务

实现具有智能自动化的全面冲突解决:

**解决操作**: 使用 $ARGUMENTS 指定检测冲突、使用策略解决、分析模式、配置规则或生成报告

**冲突解决框架**:
1. **冲突检测** - 扫描同步项,比较字段版本,识别时序冲突,标记结构问题
2. **智能解决** - 应用解决策略,处理字段合并,保留关键数据,维护关系
3. **模式分析** - 研究冲突趋势,识别频繁问题,建议流程改进,优化策略
4. **配置管理** - 设置解决偏好,定义字段优先级,配置合并规则,保存自动化设置
5. **报告与分析** - 生成冲突报告,跟踪解决成功率,分析团队模式,提供洞察
6. **自动预防** - 实现锁定机制,优化同步时序,启用变更通知,减少冲突

**解决策略**: 最新优先、智能字段级合并、手动交互解决、系统优先解决、基于自定义规则解决。

**质量保证**: 解决前备份,变更后验证,回滚能力,全面审计跟踪。

**输出**: 已解决的冲突,包含详细解决报告、更新的同步状态、模式分析洞察和优化的冲突预防策略。
