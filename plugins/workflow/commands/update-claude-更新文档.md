# Update CLAUDE.md 命令

你应该更新 `CLAUDE.md` 或 `.claude/CLAUDE.md` 文件以反映代码库的最新主要变化。

## 目的

CLAUDE.md 文件充当高级指南，帮助 Claude Code（和其他 AI 助手）理解：
- 项目结构和组织
- 关键架构决策
- 重要的约定和模式
- 在哪里找到东西
- 需要注意什么

## 何时更新

在以下情况后更新 CLAUDE.md：
- 重大重构或重组
- 添加新功能或模块
- 架构或模式变化
- 依赖项或工具更新
- 约定或标准变化
- 新目录或重要文件移动

## 应包含什么

### 1. 项目概述
- 项目功能的简要描述
- 技术栈和关键依赖
- 开发设置说明

### 2. 架构与结构
```markdown
## 项目结构

- `/src` - 主应用代码
  - `/components` - React 组件
  - `/services` - 业务逻辑和 API 调用
  - `/utils` - 辅助函数
  - `/types` - TypeScript 类型定义
- `/tests` - 测试文件
- `/docs` - 文档
- `/scripts` - 构建和实用脚本
```

### 3. 关键模式与约定
- 代码组织模式
- 命名约定
- 状态管理方法
- 错误处理模式
- 测试策略

### 4. 重要说明
- 陷阱或常见错误
- 性能考虑
- 安全要求
- 浏览器/平台支持
- 第三方集成

### 5. 开发工作流
- 如何本地运行
- 如何运行测试
- 如何构建
- 如何部署
- 分支策略

## 格式示例

```markdown
# 项目名称

## 概述
项目及其目的的简要描述。

## 技术栈
- 框架/语言
- 关键库和工具
- 数据库
- 基础设施

## 项目结构
[如上所示的详细结构]

## 架构
描述高层架构：
- 前端架构（React、状态管理）
- 后端架构（API 结构、服务）
- 数据库设计
- 外部集成

## 关键约定
- 文件命名：组件使用 kebab-case，工具使用 camelCase
- 组件结构：带 hooks 的函数式组件
- 状态管理：全局状态使用 Redux Toolkit
- 样式：CSS Modules 与 BEM 命名
- 测试：Jest + React Testing Library

## 重要说明
- 认证使用存储在 httpOnly cookies 中的 JWT tokens
- API 速率限制为每分钟 100 个请求
- 图片上传由 AWS S3 处理
- 后台任务使用带 Redis 的 Bull 队列

## 开发
```bash
# 安装依赖
npm install

# 本地运行
npm run dev

# 运行测试
npm test

# 生产构建
npm run build
```

## 在哪里找到东西
- API 端点: `/src/routes`
- 数据库模型: `/src/models`
- 认证逻辑: `/src/middleware/auth.js`
- 邮件模板: `/src/templates/email`

## 常见任务
- 添加新 API 端点：在 `/src/routes` 中创建路由，在 `/src/controllers` 中添加控制器
- 添加新数据库表：在 `/migrations` 中创建迁移，在 `/src/models` 中添加模型
- 添加新 React 页面：在 `/src/pages` 中创建组件，在 `/src/App.js` 中添加路由
```

## 你的任务

1. **定位 CLAUDE.md 文件**（如果不存在则创建）
   - 检查 `CLAUDE.md` 或 `.claude/CLAUDE.md`
   - 如果都不存在，创建 `.claude/CLAUDE.md`

2. **审查最近的变化**
   - 查看 git 历史记录的主要变化
   - 审查当前项目结构
   - 注意任何新模式或约定

3. **更新文件**
   - 为新功能/模块添加新部分
   - 更新结构图
   - 记录新约定或模式
   - 更新任何过时信息
   - 添加关于最近主要变化的说明

4. **保持简洁但全面**
   - 专注于理解代码库的重要内容
   - 不要重复其他地方已存在的文档（链接到它）
   - 突出从代码本身不明显的内容

## 记住

- CLAUDE.md 是一个动态文档 - 它应该随着代码库演进
- 专注于有助于理解大局的信息
- 要足够具体以有用，但要足够高级以保持相关性
- 主动更新它，而不只是在被要求时
- 考虑什么能帮助代码库的新人（或 AI）快速定位
