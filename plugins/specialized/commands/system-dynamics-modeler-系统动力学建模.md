# System Dynamics Modeler

通过全面的反馈分析和涌现行为预测建模复杂系统动态: **$ARGUMENTS**

## 任务

构建包含反馈循环和涌现行为分析的全面系统动力学模型:

**系统动力学框架**:
1. **系统架构** - 存量和流量识别、因果循环映射和边界定义
2. **反馈结构** - 强化循环、平衡循环和延迟建模,包含政策阻力分析
3. **动态模拟** - 基于时间的行为分析、场景测试和敏感性分析
4. **涌现行为** - 非线性效应、意外后果和系统原型识别
5. **政策测试** - 干预分析、杠杆点识别和策略优化
6. **学习实验室** - 假设实验、心理模型测试和洞察生成

**输出**: 完整的系统动力学模型,包含因果结构、模拟结果、政策建议以及用于复杂系统优化和管理的战略洞察。
