# Convert Code Analysis to Linear Tasks

将代码分析转换为 Linear 任务

## 目的
此命令扫描您的代码库中的 TODO/FIXME 注释、技术债务标记、已弃用代码和其他应被跟踪的指示器。它自动创建有组织的、优先级排序的 Linear 任务,确保重要的代码改进不会被遗忘。

## 使用方法

```bash
# 扫描整个代码库中的 TODO 并创建任务
claude "从代码库中的所有 TODO 注释创建任务"

# 扫描特定目录或模块
claude "查找 src/api 中的 TODO 并创建 Linear 任务"

# 从特定模式创建任务
claude "为所有已弃用的函数创建任务"

# 生成技术债务报告
claude "分析项目中的技术债务并创建改进任务"
```

## 主要步骤

1. **扫描任务标记** - 搜索 TODO、FIXME、HACK、XXX、OPTIMIZE、REFACTOR 等
2. **解析注释上下文** - 提取类型、优先级、标题、描述、作者、日期、标签
3. **分组和去重** - 按文件、类型、作者、模块分组任务
4. **分析技术债务** - 识别长函数、重复代码、复杂条件、过时依赖
5. **创建 Linear 任务** - 转换为可操作的任务,避免重复
6. **生成摘要报告** - 创建发现概览和建议

## 提示
- 定期运行以防止 TODO 积累
- 在团队中使用一致的注释格式
- 在 TODO 中包含作者和日期
- 尽可能将 TODO 链接到现有 Linear 问题
- 设置 IDE 片段以正确格式化 TODO
- 审查并关闭已完成的 TODO 任务
