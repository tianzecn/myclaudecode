# Monte Carlo Simulator

通过高级统计分析运行全面的蒙特卡洛模拟: **$ARGUMENTS**

## 任务

执行包含全面不确定性量化的复杂蒙特卡洛模拟:

**蒙特卡洛框架**:
1. **变量定义** - 不确定参数识别、概率分布选择和相关性建模
2. **模拟引擎** - 随机采样、场景生成和统计收敛分析
3. **输出分析** - 概率分布、置信区间和敏感性分析
4. **风险量化** - 风险价值(VaR)、极端场景分析和尾部风险评估
5. **场景聚类** - 模式识别、结果分类和决策相关分组
6. **决策整合** - 风险调整建议、优化策略和应急规划

**输出**: 完整的蒙特卡洛分析,包含概率分布、风险指标、场景分析和具有量化置信水平的统计基础决策建议。
