# Intelligent Refactoring Engine

我将帮助您系统地重构代码 - 在保持功能的同时改进结构、可读性和可维护性。

参数: `$ARGUMENTS` - 文件、目录或重构范围

**关键特性: 每次更改后内置验证和改进确保不会破坏任何内容,不会遗漏任何代码。AI 将在重构过程中自动修复自己的错误。**

**会话文件位置: 始终使用当前目录中的 refactor/ 文件夹**

## 会话智能

**会话文件(在当前项目中)**:
- `refactor/plan.md` - 重构计划和进度跟踪
- `refactor/state.json` - 当前状态和已完成的操作

**重要**: `refactor` 文件夹在您的当前项目目录中创建。使用 `refactor/` 访问它。

## 主要阶段

1. **初始设置和分析** - 检查会话、分析代码库、识别改进机会
2. **重构规划** - 创建结构化计划
3. **增量执行** - 系统应用重构
4. **模式应用** - 应用一致的模式
5. **质量指标** - 跟踪重构影响

## 持续验证和改进

每次重构更改后:
1. **即时测试** - 运行单元测试和集成测试
2. **深度比较** - 比较更改前后的函数输出
3. **自动修复** - 自动更新损坏的导入和引用
4. **质量关卡** - 测试失败时停止并立即修复
5. **持续改进** - 重新扫描遗漏的模式并更新所有相关文件

## 自动最终验证和改进

**自动执行**: 此阶段在所有重构完成后自动运行。您也可以使用 `/refactor validate` 手动触发。

**最终验证过程**:
1. 覆盖检查 - 查找所有剩余的旧模式
2. 导入验证 - 检测损坏或孤立的导入
3. 构建和测试 - 运行完整的构建和测试套件
4. 类型检查 - 验证类型安全性
5. 死代码检测 - 识别可移除的遗留代码

## 深度验证命令

运行 `/refactor finish`、`/refactor enhance`、`/refactor verify` 或 `/refactor complete`:

**自动执行所有这些步骤**:
1. 深度原始代码分析
2. 完整迁移
3. 深度代码对代码比较
4. 全面分析
5. 自动修复
6. 最终验证
7. 完整报告

**结果**: 100% 保证没有任何东西被破坏,没有任何东西被遗漏,应用程序的行为与重构前完全相同。

## 安全保证

- 更改前的 Git 检查点
- 逻辑点的增量提交
- 每步后的测试验证
- 清晰的回滚策略

我将确保会话间完美的连续性,始终从我们停止的地方恢复,保持完整的上下文和决策历史。
