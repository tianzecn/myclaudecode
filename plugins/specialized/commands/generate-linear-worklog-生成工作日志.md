# Generate Linear Work Log

您的任务是根据最近的 git 提交为 Linear issue 生成技术工作日志注释。

## 说明

1. **检查 Linear MCP 可用性** - 验证 Linear MCP 工具可用
2. **检查现有工作日志** - 查找今天日期的现有注释
3. **提取 Git 信息** - 获取当前分支和最近提交
4. **生成工作日志内容** - 使用干燥的技术语言,无形容词或表情符号
5. **处理现有工作日志** - 如果存在则更新,否则创建新的
6. **发布到 Linear** - 创建或更新注释

## 格式结构

```
## Work Completed [今天日期]

### Branch: [当前分支名]

**Commit [短哈希]: [提交标题]**
- [技术细节 1]
- [技术细节 2]
- [行数] 行代码,涉及 [文件数] 个文件

### [状态部分]
- [当前基础设施/测试状态]
- [现在可用/就绪的内容]
```

## 内容指南

- 包含提交哈希和描述性标题
- 提供具体的技术实现
- 包含重要更改的文件数和行数
- 保持一致的格式
- 关注技术成就
- 无表情符号或特殊字符
