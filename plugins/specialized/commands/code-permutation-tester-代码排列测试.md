# Code Permutation Tester

通过模拟在实施前测试多个代码变体,使用质量关卡和性能预测来优化决策。

## 说明

您的任务是通过模拟系统地测试多个代码实现方法,以在实际开发前优化决策。遵循以下方法: **$ARGUMENTS**

### 关键功能

**核心目的**: 在编写代码前测试多种实现方案,通过模拟选择最佳方法

**主要阶段**:
1. **先决条件评估** - 代码范围、变体类型、质量标准、约束条件
2. **代码变体生成** - 算法变体、架构变体、技术栈变体、性能配置
3. **模拟框架设计** - 性能模拟、可维护性模拟、可扩展性模拟、安全模拟
4. **质量关卡框架** - 多标准评估矩阵(性能、可维护性、可靠性、业务)
5. **预测性能建模** - 微基准、集成性能、系统级性能、生产环境预测
6. **风险和权衡分析** - 技术风险、运营风险、业务风险
7. **决策矩阵和建议** - 变体比较、详细分析、成功指标
8. **持续学习整合** - 实施验证、知识捕获

**质量指标**:
- 绿色: 测试多个变体、全面质量关卡、已验证的性能预测
- 黄色: 测试部分变体、基本质量评估、估计性能
- 红色: 单一方法、最小测试、未验证假设

将代码实施从猜测转变为系统化、基于证据的决策。
