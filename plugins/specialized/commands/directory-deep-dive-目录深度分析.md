# 目录深度分析

分析目录结构和用途

## 说明

1. **目标目录**
   - 专注于 `$ARGUMENTS` 指定的目录或当前工作目录

2. **调查架构**
   - 分析此目录及其子目录中代码的实现原则和架构
   - 查找:
     - 使用的设计模式
     - 依赖及其用途
     - 关键抽象和接口
     - 命名约定和代码组织

3. **创建或更新文档**
   - 创建 CLAUDE.md 文件来捕获这些知识
   - 如果已存在,则用新发现的信息更新
   - 包括:
     - 此模块的目的和职责
     - 关键架构决策
     - 重要实现细节
     - 整个代码中使用的常见模式
     - 任何陷阱或非明显行为

4. **确保正确放置**
   - 将 CLAUDE.md 文件放在被分析的目录中
   - 这确保在特定区域工作时加载上下文
