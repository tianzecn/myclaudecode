# Simulation Calibrator

通过全面验证和持续改进校准模拟准确性: **$ARGUMENTS**

## 任务

实施包含全面准确性改进的系统模拟校准:

**校准框架**:
1. **基线评估** - 历史验证、准确性指标和错误模式分析
2. **偏见检测** - 系统识别认知、数据和模型偏见,并制定缓解策略
3. **验证循环** - 多级验证,包括内部一致性、专家审查和实证测试
4. **实时校准** - 持续监控、自动调整和自适应学习整合
5. **质量保证** - 元校准评估和改进可持续性
6. **改进路线图** - 系统化增强策略,包含性能跟踪

**输出**: 校准的模拟,包含已验证的准确性指标、偏见纠正报告、持续改进系统和增强的决策支持可靠性。
