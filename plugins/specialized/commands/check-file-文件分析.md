# 文件分析工具

对 $ARGUMENTS 进行全面分析,识别代码质量问题、安全漏洞和优化机会

## 任务

我将分析指定文件并提供详细见解:

1. 代码质量指标和可维护性
2. 安全漏洞和最佳实践
3. 性能瓶颈和优化机会
4. 依赖使用和潜在问题
5. TypeScript/JavaScript 特定模式和改进
6. 测试覆盖和缺失测试

## 流程

我将遵循以下步骤:

1. 读取和解析目标文件
2. 分析代码结构和复杂度
3. 检查安全漏洞和反模式
4. 评估性能影响
5. 审查依赖使用和导入
6. 提供可操作的改进建议

## 分析领域

### 代码质量
- 圈复杂度和可维护性指标
- 代码重复和重构机会
- 命名约定和代码组织
- TypeScript 类型安全和最佳实践

### 安全评估
- 输入验证和清理
- 认证和授权模式
- 敏感数据暴露风险
- 常见漏洞模式 (XSS、注入等)

### 性能审查
- 打包大小影响和优化机会
- 运行时性能瓶颈
- 内存使用模式
- 懒加载和代码分割机会

### 最佳实践
- 框架特定模式 (React、Vue、Angular)
- 现代 JavaScript/TypeScript 特性使用
- 错误处理和日志记录实践
- 测试模式和覆盖缺口

我将提供针对您项目技术栈和架构的具体、可操作的建议。
