# Enhanced AI Mode for Complex Tasks

复杂任务的增强 AI 模式

*命令最初由 IndyDevDan 创建 (YouTube: https://www.youtube.com/@indydevdan) / DislerH (GitHub: https://github.com/disler)*

## 说明

使用全面的项目上下文初始化新的 Claude Code 会话:

1. **分析代码库结构** - 运行 `git ls-files` 了解文件组织和项目布局
2. **阅读项目文档** - 阅读 README.md、docs/、ai_docs/ 等
3. **理解项目上下文** - 识别项目的主要目的和目标
4. **提供简洁概览** - 用 2-3 句话总结项目目的

此命令在以下情况下帮助快速建立上下文:
- 开始新项目工作
- 离开一段时间后返回项目
- 新团队成员入职
- 准备深入技术工作

目标是为 AI 助手"准备"必要的项目知识以提供更有效的帮助。
