# Remove Obvious Comments

我将清理冗余注释,同时保留有价值的文档。

## 分析过程

我将使用以下工具识别带注释的文件:
- **Glob** 查找源文件
- **Read** 检查注释模式
- **Grep** 定位特定注释类型

**我将删除的注释**:
- 只是重申代码功能的
- 除了代码本身之外不添加任何价值的
- 陈述明显内容的(如构造函数上方的"构造函数")

**我将保留的注释**:
- 解释为什么做某事的
- 记录复杂业务逻辑的
- 包含 TODO、FIXME 或 HACK 的
- 警告非显而易见行为的
- 提供重要上下文的

## 审查过程

对于每个包含明显注释的文件,我将:
1. 向您展示我发现的冗余注释
2. 解释为什么应该删除它们
3. 显示更干净的版本
4. 在您确认后应用更改

这创建了更清洁、更可维护的代码,其中每个注释都有实际价值。
