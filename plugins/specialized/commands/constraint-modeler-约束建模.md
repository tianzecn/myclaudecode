# Constraint Modeler

通过系统验证和优化建模全面的系统约束: **$ARGUMENTS**

## 当前系统背景

- 领域范围: 基于 $ARGUMENTS (业务、技术、运营、财务)
- 现有约束: @documentation 或配置文件
- 系统边界: 当前限制和依赖
- 变化动态: 历史约束演变模式

## 任务

创建全面的约束模型以实现准确的模拟和决策:

**约束领域**: 使用 $ARGUMENTS 关注业务、技术、监管或资源约束

**约束框架**:
1. **硬约束** - 不可违反的绝对限制 (法律、物理、技术)
2. **软约束** - 可以管理的偏好和权衡 (预算、质量、时间)
3. **动态约束** - 随时间演变的限制 (市场、技术、容量)
4. **约束依赖** - 不同限制之间的关系和交互
5. **验证框架** - 验证约束准确性和相关性的方法
6. **优化策略** - 放松、替代或规避约束的方法

**高级分析**: 约束敏感性分析、瓶颈识别、场景边界定义和优化算法。

**战略应用**: 将约束模型链接到决策场景、资源分配和战略规划。

**输出**: 包含交互矩阵的完整约束模型、验证报告、优化建议和场景边界定义。
