# Smart Implementation Engine

我将从任何来源智能实现功能 - 完美适配您的项目架构,同时保持您的代码模式和标准。

参数: `$ARGUMENTS` - URL、路径或要实现的功能描述

## 会话智能

**会话文件(在当前项目中)**:
- `implement/plan.md` - 当前实现计划和进度
- `implement/state.json` - 会话状态和检查点

**重要**: 会话文件存储在当前项目根目录的 `implement` 文件夹中

## 主要阶段

1. **初始设置和分析** - 检查会话、分析来源、理解项目
2. **战略规划** - 创建详细的实现计划
3. **智能适配** - 转换以完美适配您的项目
4. **实现执行** - 增量应用更改
5. **质量保证** - 验证一切正常工作

## 深度验证

运行 `/implement finish`、`/implement verify`、`/implement complete` 或 `/implement enhance`:

自动执行:
1. 深度原始源代码分析
2. 需求验证
3. 全面测试
4. 深度代码分析
5. 自动改进
6. 集成分析
7. 完整性报告

**结果**: 100% 完整、经过测试且可用于生产的实现,符合所有要求。
