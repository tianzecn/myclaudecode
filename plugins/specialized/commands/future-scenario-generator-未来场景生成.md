# Future Scenario Generator

通过系统分析和战略整合生成全面的未来场景: **$ARGUMENTS**

## 当前趋势背景

- 时间范围: 基于 $ARGUMENTS (1-2年、3-5年、5-10+年)
- 领域焦点: 行业、技术、社会或经济场景生成
- 现有趋势: 当前模式、轨迹和新兴发展
- 关键变量: 可能塑造未来结果的主要因素

## 任务

创建包含全面分析和战略影响的系统未来场景:

**时间范围**: 使用 $ARGUMENTS 关注近期、中期、长期或颠覆性场景

**场景框架**:
1. **趋势分析** - 跨技术、社会、经济和监管领域的多维趋势识别
2. **场景架构** - 基准、乐观、悲观和转型场景,带交叉影响分析
3. **可信度评估** - 基于历史先例、逻辑一致性和专家验证的多标准评分
4. **黑天鹅整合** - 低概率、高影响事件和颠覆建模
5. **战略影响** - 决策相关见解和稳健策略识别
6. **监控框架** - 早期预警指标和场景跟踪系统

**输出**: 包含可信度评分、战略影响、监控指标和多种未来可能性决策框架的全面场景组合。
