理解Bug：$ARG

开始之前：
- GITHUB：创建一个带有简短描述性标题的 Issue。
- GIT：检出一个分支并切换到它。

修复Bug

完成后：
- GIT：提交并附上描述性消息。
- GIT：将分支推送到远程仓库。
- GITHUB：创建 PR 并关联该 Issue。
