# 全面的 PR 审查模板

这是一个包含六个不同审查任务的全面 PR（Pull Request）审查模板：

## 1. 产品经理审查
- 关注业务价值、用户体验和战略一致性

## 2. 开发者审查
- 评估代码质量、性能和遵循最佳实践的情况

## 3. 质量工程师审查
- 检查测试覆盖率、潜在 Bug 和回归风险

## 4. 安全工程师审查
- 评估安全漏洞、数据处理和合规性

## 5. DevOps 审查
- 验证 CI/CD 流水线、基础设施和监控考虑因素

## 6. UI/UX 设计师审查
- 确保视觉一致性、可用性和交互流程

## 关键主题
该文档强调对改进采取紧急、立即的方法，反复强调"未来"的建议应该立即解决，而不是推迟。

每个部分遵循类似的结构：
- 一个目标
- 要审查的具体领域
- 一个要求立即实施任何建议改进的行动项

该模板旨在为软件开发 Pull Request 提供全面的多角度审查。
