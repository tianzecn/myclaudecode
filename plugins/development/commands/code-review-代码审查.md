## 上下文

- 当前 git 状态：!`git status`
- 最近更改：!`git diff HEAD~1`
- 最近提交：!`git log --oneline -5`
- 当前分支：!`git branch --show-current`

## 你的任务

执行全面的代码审查，重点关注：

1. **代码质量**：检查可读性、可维护性以及是否遵守最佳实践
2. **安全性**：寻找潜在漏洞或安全问题
3. **性能**：识别潜在的性能瓶颈
4. **测试**：评估测试覆盖率和质量
5. **文档**：检查代码是否有适当的文档

提供具体的、可操作的反馈，并在适当时提供逐行注释。
