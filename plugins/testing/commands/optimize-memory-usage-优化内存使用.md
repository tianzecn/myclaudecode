# 优化内存使用

分析并优化内存使用模式以防止泄漏并提升应用性能:**$ARGUMENTS**

## 说明

1. **内存分析和分析** - 使用适当工具分析当前内存使用模式
2. **内存泄漏检测** - 为不同运行时环境设置内存泄漏检测
3. **垃圾回收优化** - 为运行时环境配置垃圾回收设置
4. **内存池和对象重用** - 为频繁分配的对象实现对象池
5. **字符串和文本优化** - 为常用字符串实现字符串驻留
6. **数据库连接优化** - 使用适当限制实现连接池
7. **前端内存优化** - 优化组件生命周期和清理
8. **后端内存优化** - 优化服务器请求处理和清理
9. **容器和部署优化** - 配置适当的容器内存限制
10. **内存监控和告警** - 设置实时内存监控仪表板

专注于为目标环境提供最大影响的内存优化策略。始终在优化前后测量内存使用以量化改进。
