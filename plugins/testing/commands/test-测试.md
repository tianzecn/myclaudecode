# 智能测试运行器 - 上下文感知

我将根据您的当前上下文智能运行测试并主动帮助修复失败。

**首先进行上下文检测:**

1. **冷启动**(无先前上下文): 运行完整测试套件并生成完整健康报告
2. **活动会话**(您正在实现功能): 检查git diff查找修改的文件,仅测试您正在工作的内容
3. **后命令上下文**: 根据之前的命令运行相关测试
4. **调试上下文**(之前的测试失败): 专注于失败的测试并提供详细输出
5. **预提交上下文**: 完整套件 + lint + 类型检查

## 阶段1: 深度项目分析
使用原生工具了解您的测试设置

## 阶段2: 智能测试执行
我将根据您项目的测试框架运行测试

## 阶段3: 失败分析和自动修复
当测试失败时,我将:
1. 解析失败输出以了解确切问题
2. 阅读失败测试以了解期望
3. 阅读实现以找到错误
4. 分析通过的类似测试模式
5. 在有信心时应用修复

这确保您的测试真正验证您的代码,同时最大化开发速度。
