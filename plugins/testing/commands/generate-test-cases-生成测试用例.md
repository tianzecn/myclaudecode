# 生成测试用例

生成全面的测试用例,包含自动分析和智能覆盖:**$ARGUMENTS**

## 当前测试生成上下文

- 目标代码: 分析 $ARGUMENTS 以确定测试用例生成需求
- 测试框架: !`find . -name "jest.config.*" -o -name "*.test.*" | head -1 && echo "检测到Jest/Vitest" || echo "检测框架"`
- 代码复杂度: !`find . -name "*.js" -o -name "*.ts" -o -name "*.py" | xargs wc -l 2>/dev/null | tail -1 | awk '{print $1}' || echo "0"` 行代码
- 现有模式: !`find . -name "*.test.*" -o -name "*.spec.*" | head -3` 测试文件模式

## 任务

执行智能测试用例生成,包含全面覆盖和优化:

**生成范围**: 使用 $ARGUMENTS 指定目标文件、单元测试、集成测试、边缘情况或自动全面生成

**测试用例生成框架**:

1. **代码结构分析** - 解析函数签名,分析控制流,识别分支路径,评估复杂度指标
2. **测试模式识别** - 分析现有测试模式,识别测试约定,提取可重用模式,优化一致性
3. **输入空间分析** - 识别参数域,分析边界条件,发现边缘情况,评估错误条件
4. **测试用例设计** - 生成正向测试用例、负向测试用例、边界值测试、等价类测试
5. **Mock 策略规划** - 识别外部依赖,设计 mock 实现,创建测试数据工厂,优化测试隔离
6. **覆盖率优化** - 确保路径覆盖,优化测试效率,消除冗余,最大化测试价值

**高级功能**: 自动边缘情况发现、智能输入生成、测试数据合成、覆盖率差距分析、性能测试生成。

**质量保证**: 测试可维护性、执行性能、断言质量、调试有效性。

**输出**: 全面的测试用例套件,包含优化的覆盖率、智能 mock、适当的断言和维护指南。
