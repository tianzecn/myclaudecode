# 添加性能监控

配置应用性能监控:**$ARGUMENTS**

## 说明

1. **性能监控策略**
   - 定义关键性能指标 (KPI) 和服务级别目标 (SLO)
   - 识别关键用户旅程和性能瓶颈
   - 规划监控架构和数据收集策略
   - 评估现有监控基础设施和集成点
   - 定义告警阈值和升级程序

2. **应用性能监控 (APM)**
   - 设置全面的 APM 解决方案 (New Relic、Datadog、AppDynamics)
   - 配置分布式追踪以实现请求生命周期可见性
   - 实现自定义指标和性能跟踪
   - 设置事务监控和错误跟踪
   - 配置性能分析和诊断

3. **真实用户监控 (RUM)**
   - 实现客户端性能跟踪和 Web 核心指标监控
   - 设置用户体验指标收集 (LCP、FID、CLS、TTFB)
   - 配置用户交互的自定义性能指标
   - 监控页面加载性能和资源加载
   - 跟踪不同设备的用户旅程性能

4. **服务器性能监控**
   - 监控系统指标 (CPU、内存、磁盘、网络)
   - 设置进程和应用级别监控
   - 配置事件循环延迟和垃圾回收监控
   - 实现自定义服务器性能指标
   - 监控资源利用率和容量规划

5. **数据库性能监控**
   - 跟踪数据库查询性能和慢查询识别
   - 监控数据库连接池利用率
   - 设置数据库性能指标和告警
   - 实现查询执行计划分析
   - 监控数据库资源使用和优化机会

6. **错误跟踪和监控**
   - 实现全面的错误跟踪 (Sentry、Bugsnag、Rollbar)
   - 配置错误分类和影响分析
   - 设置错误告警和通知系统
   - 跟踪错误趋势和解决指标
   - 实现错误上下文和调试信息

7. **自定义指标和仪表板**
   - 实现业务指标跟踪 (Prometheus、StatsD)
   - 创建性能仪表板和可视化
   - 配置自定义告警规则和阈值
   - 设置性能趋势分析和报告
   - 实现性能回归检测

8. **告警和通知系统**
   - 基于性能阈值配置智能告警
   - 设置多渠道通知 (邮件、Slack、PagerDuty)
   - 实现告警升级和值班程序
   - 配置告警疲劳预防和噪音降低
   - 设置性能事件管理工作流

9. **性能测试集成**
   - 将监控与负载测试和性能测试集成
   - 设置持续性能测试和监控
   - 配置性能基线跟踪和比较
   - 实现性能测试结果分析和报告
   - 监控不同负载场景下的性能

10. **性能优化建议**
    - 生成可操作的性能洞察和建议
    - 实现自动化性能分析和报告
    - 设置性能优化跟踪和测量
    - 配置性能改进验证
    - 创建性能优化优先级框架

专注于能够为性能优化提供可操作洞察的监控策略。确保监控开销最小,不会影响应用性能。
