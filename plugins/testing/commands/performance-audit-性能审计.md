# 性能审计

执行全面性能审计: $ARGUMENTS

## 当前性能上下文

- 包分析: !`npm run build -- --analyze 2>/dev/null || echo "无构建分析器"`
- 依赖: !`npm list --depth=0 --prod 2>/dev/null | head -10`

## 任务

按照以下步骤执行全面性能审计:

1. **技术栈分析** - 识别主要语言、框架和运行时环境
2. **代码性能分析** - 识别低效算法和数据结构
3. **数据库性能** - 分析数据库查询效率
4. **前端性能** - 分析包大小和分块优化
5. **网络性能** - 审查API调用模式和缓存策略
6. **异步操作** - 审查async/await使用和promise处理
7. **内存使用** - 检查内存泄漏和过度消耗
8. **构建与部署性能** - 分析构建时间和优化机会
9. **性能监控** - 检查现有性能指标和监控
10. **优化建议** - 按影响和工作量优先排序优化

在可能的情况下包含具体文件路径、行号和可测量指标。优先考虑高影响、低工作量的优化。
