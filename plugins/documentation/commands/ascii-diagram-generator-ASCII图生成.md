<任务定义>
生成符合严格约束的 **ASCII 架构图/流程图/示意图**。
模型在绘图时必须完全遵循下述格式规范，避免使用非 ASCII 字符或任意导致错位的排版。
</任务定义>

<核心规范>

<对齐与结构规则>
## 1. 对齐与结构规则（Alignment Requirements）

1. 图中所有字符均需使用 **等宽字符（monospace）** 对齐
2. 所有框体（boxes）必须保证：
   - 上下左右边界连续无断裂
   - 宽度一致（除非任务明确允许可变宽度）
   - 框体间保持水平对齐或垂直对齐的整体矩形布局
3. 图中所有箭头（`---->`, `<====>`, `<----->` 等）需在水平方向严格对齐，并位于框体之间的**中线位置**
4. 整图不得出现可视上的倾斜、错位、参差不齐等情况
</对齐与结构规则>

<字符限制>
## 2. 字符限制（Allowed ASCII Character Set）

仅允许使用以下基础 ASCII 字符构图：

```
+ - |  <  >  =  /  \  *  .  :  _  (空格)
```

**禁止使用任意 Unicode box-drawing 字符**（如：`┌ ─ │ ┘` 等）
</字符限制>

<框体规范>
## 3. 框体规范（Box Construction Rules）

框体必须采用标准结构：

```
+---------+
| text    |
+---------+
```

要求如下：
- 上边和下边：由 `+` 与连续的 `-` 组成
- 左右边：使用 `|`
- 框内文本需保留至少 **1 格空白**间距
- 文本必须保持在框内的合理位置（居中或视觉居中，不破坏结构）
</框体规范>

<连接线与箭头>
## 4. 连接线与箭头（Connections & Arrows）

可使用以下箭头样式：

```
<=====>      ----->      <----->
```

规则如下：
1. 箭头需紧贴两个框体之间的中心水平线
2. 连接协议名称（如 HTTP、WebSocket、SSH 等）可放置在箭头的上方或下方
3. 协议文本必须对齐同一列，不得错位

示例：
```
+-------+    http   +-------+
|  A    |  <=====>  |   B   |
+-------+ websocket +-------+
```
</连接线与箭头>

<文本布局规则>
## 5. 文本与注释布局（Text Placement Rules）

1. 框内文本必须左右留白，不得触边
2. 框体外的说明文字需与主体结构保持垂直或水平对齐
3. 不允许出现位移使主图结构变形的注解格式
</文本布局规则>

<整体布局规则>
## 6. 整体布局规则（Overall Layout Rules）

1. 图形布局必须呈现规则矩形结构
2. 多个框体的 **高度、宽度、间距、对齐线** 需保持整齐一致
3. 多行结构必须遵循等高原则示例：

```
+--------+       +--------+
|   A    | <---> |   B    |
+--------+       +--------+
```
</整体布局规则>

</核心规范>

<工作流程>
## 执行步骤

<阶段 序号="1" 名称="需求分析">
### 阶段 1：需求分析

1. 解析用户提供的图描述内容
2. 识别需要绘制的实体（节点/框体）
3. 识别实体之间的关系（连接/箭头/协议）
4. 确定布局方向（水平/垂直/混合）
</阶段>

<阶段 序号="2" 名称="框体设计">
### 阶段 2：框体设计

1. 计算每个框体所需的宽度（文本长度 + 左右留白）
2. 统一框体高度（通常为 3 行）
3. 确保框体宽度一致或按组对齐
4. 预留连接线空间
</阶段>

<阶段 序号="3" 名称="连接规划">
### 阶段 3：连接规划

1. 确定箭头样式（单向/双向）
2. 计算连接线长度
3. 规划协议/标签文字位置
4. 确保垂直对齐
</阶段>

<阶段 序号="4" 名称="图形生成">
### 阶段 4：图形生成

1. 按行构建 ASCII 图形
2. 严格对齐每个字符位置
3. 验证框体边界完整性
4. 检查整体矩形布局
</阶段>

<阶段 序号="5" 名称="质量验证">
### 阶段 5：质量验证

**验证清单：**
- [ ] 所有框体边界连续无断裂
- [ ] 箭头位于框体中心线位置
- [ ] 协议文本垂直对齐
- [ ] 无 Unicode box-drawing 字符
- [ ] 整体布局呈规则矩形
- [ ] 框内文本留白充足
</阶段>

</工作流程>

<常见图形模式>
## 常见图形模式

### 模式 1：线性流程（水平）
```
+-----+     +-----+     +-----+
|  A  | --> |  B  | --> |  C  |
+-----+     +-----+     +-----+
```

### 模式 2：线性流程（垂直）
```
+-----+
|  A  |
+-----+
   |
   v
+-----+
|  B  |
+-----+
   |
   v
+-----+
|  C  |
+-----+
```

### 模式 3：双向通信
```
+--------+              +--------+
| Client | <==========> | Server |
+--------+    TCP/IP    +--------+
```

### 模式 4：分支结构
```
              +-----+
              |  A  |
              +-----+
                 |
        +--------+--------+
        |                 |
        v                 v
     +-----+           +-----+
     |  B  |           |  C  |
     +-----+           +-----+
```

### 模式 5：网格布局
```
+-----+     +-----+     +-----+
|  A  | --> |  B  | --> |  C  |
+-----+     +-----+     +-----+
   |           |           |
   v           v           v
+-----+     +-----+     +-----+
|  D  | --> |  E  | --> |  F  |
+-----+     +-----+     +-----+
```
</常见图形模式>
