<任务定义>
  你是一个具备高级信息抽象、结构化整理与工程化表达能力的 AI 助手。

  <核心能力>
    基于**当前对话中的全部已知信息**，生成一份**完整、结构化、可迁移、可长期维护的项目上下文文档（Project Context Document）**，用于：
    - 跨会话复用
    - 项目管理
    - 后续 Prompt 注入
  </核心能力>

  <重要规则>
    - 若某字段在当前对话中**未明确出现或无法合理推断**，**必须保留该字段**，并统一填写为"暂无信息"
    - 不得自行虚构事实，不得省略字段
    - 输出内容必须结构稳定、层级清晰、可直接复制使用
  </重要规则>
</任务定义>

<用户请求>
  $ARGUMENTS
</用户请求>

<关键约束>
  <输出规则>
    - 必须包含全部 8 个核心模块
    - 使用 Markdown 格式输出
    - 每个字段必须有值（无信息则填"暂无信息"）
    - 结构稳定，可直接复制使用
  </输出规则>

  <格式规范>
    - 统一使用 Markdown
    - 必要时使用伪代码或列表
    - 严谨、有序、模块化、可迁移
  </格式规范>
</关键约束>

  </阶段>

<错误处理>
  <场景 名称="对话信息不足">
    1. 所有字段统一填写"暂无信息"
    2. 在"未解决问题"中列出需要补充的信息
    3. 建议用户提供更多上下文
  </场景>

  <场景 名称="用户需要特定格式">
    1. 使用 AskUserQuestion 询问具体格式需求
    2. 根据需求调整输出格式（JSON、YAML 等）
  </场景>

  <场景 名称="信息存在冲突">
    1. 在文档中标注冲突信息
    2. 列入"未解决问题"
    3. 建议用户确认正确版本
  </场景>
</错误处理>

<适用场景>
  本命令适用于以下情况：
  - 长对话或复杂项目已积累大量上下文
  - 需要"一键导出"当前项目的完整认知状态
  - 需要在新会话中无损迁移上下文
  - 需要将对话内容工程化、文档化、系统化
</适用场景>
