# 开发者入职指南生成器

创建开发者入职指南：$ARGUMENTS

## 当前团队上下文

- 项目设置：@package.json 或 @requirements.txt 或 @Cargo.toml（检测技术栈）
- 现有文档：@docs/ 或 @README.md（如果存在）
- 开发工具：!`find . -name ".env*" -o -name "docker-compose.yml" -o -name "Makefile" | head -3`
- 团队结构：@CODEOWNERS 或 @.github/（如果存在）
- CI/CD 设置：!`find .github/workflows -name "*.yml" 2>/dev/null | head -3`

## 任务

创建针对角色和项目需求定制的全面入职体验：

1. **入职需求分析**
   - 分析当前团队结构和技能要求
   - 识别关键知识领域和学习目标
   - 评估当前入职挑战和痛点
   - 定义入职时间表和里程碑期望
   - 记录角色特定要求和职责

2. **开发环境设置指南**
   - 创建全面的开发环境设置说明
   - 记录所需工具、软件和系统要求
   - 提供分步安装和配置指南
   - 创建环境验证和故障排除程序
   - 设置自动化环境设置脚本和工具

3. **项目和代码库概述**
   - 创建高级项目概述和业务上下文
   - 记录系统架构和技术栈
   - 提供代码库结构和组织指南
   - 创建代码导航和探索指南
   - 记录使用的关键模块、库和框架

4. **开发工作流文档**
   - 记录版本控制工作流和分支策略
   - 创建代码审查流程和质量标准指南
   - 记录测试实践和要求
   - 提供部署和发布流程概述
   - 创建问题跟踪和项目管理工作流指南

5. **团队沟通与协作**
   - 记录团队沟通渠道和协议
   - 创建会议日程和参与指南
   - 提供团队联系信息和组织架构图
   - 记录协作工具和访问程序
   - 创建升级程序和支持联系人

6. **学习资源和培训材料**
   - 整理项目特定技术的学习资源
   - 创建实践教程和编码练习
   - 提供文档、wiki 和知识库的链接
   - 创建视频教程和屏幕录像
   - 设置导师制度和伙伴系统程序

7. **首个任务和里程碑**
   - 创建渐进难度的任务分配
   - 定义学习里程碑和检查点
   - 提供"适合新手的问题"和入门项目
   - 创建实践编码挑战和练习
   - 设置结对编程和跟班学习机会

8. **安全与合规培训**
   - 记录安全策略和访问控制
   - 创建数据处理和隐私指南
   - 提供合规培训和认证要求
   - 记录事件响应和安全程序
   - 创建安全最佳实践和指南

9. **工具和资源访问**
   - 记录所需账户和访问请求
   - 创建工具特定的设置和使用指南
   - 提供许可证和订阅信息
   - 记录 VPN 和网络访问程序
   - 创建常见访问问题的故障排除指南

10. **反馈和持续改进**
    - 创建入职反馈收集流程
    - 设置定期检查和进度审查
    - 记录常见问题和 FAQ 部分
    - 创建入职指标和成功跟踪
    - 建立入职指南维护和更新程序
    - 设置新员工成功监控和支持系统
