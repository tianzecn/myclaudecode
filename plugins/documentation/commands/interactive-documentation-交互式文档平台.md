# 交互式文档平台

创建带实时示例的交互式文档：$ARGUMENTS

## 当前文档基础设施

- 静态站点生成器：!`find . -name "docusaurus.config.js" -o -name "gatsby-config.js" -o -name "_config.yml" | head -3`
- 文档框架：@docs/ 或 @website/（检测现有设置）
- 组件库：!`find . -name "*.stories.*" | head -5`（Storybook 检测）
- 交互式示例：!`find . -name "*.ipynb" -o -name "*playground*" | head -3`
- 托管设置：@vercel.json 或 @netlify.toml 或 @.github/workflows/（如果存在）

## 任务

构建具有实时代码示例、用户参与功能和多平台集成能力的全面交互式文档平台。
