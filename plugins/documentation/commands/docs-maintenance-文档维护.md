# 文档维护与质量保证

实现全面的文档维护系统：$ARGUMENTS

## 当前文档健康状况

- 文档文件：!`find . -name "*.md" -o -name "*.mdx" | wc -l` 个文件
- 最后更新：!`find . -name "*.md" -exec stat -f "%m %N" {} \; | sort -n | tail -5`
- 外部链接：!`grep -r "http" --include="*.md" . | wc -l` 个链接需验证
- 图片引用：!`grep -r "!\[.*\]" --include="*.md" . | wc -l` 个图片需检查
- 文档结构：@docs/ 或检测文档目录

## 任务

创建系统化的文档维护框架，包含自动化质量保证、全面验证、内容优化和定期更新程序。

## 文档维护框架

### 1. 内容质量审计系统
- 全面的文件发现和分类
- 内容新鲜度分析和老化检测
- 字数、可读性和结构评估
- 识别缺失部分和不完整文档
- TODO/FIXME 标记跟踪和解决计划

### 2. 链接和引用验证
- 带重试逻辑的外部链接健康监控
- 内部链接验证和损坏引用检测
- 图片引用验证和缺失资源识别
- 交叉引用一致性检查
- 自动化链接修正建议

### 3. 样式和一致性检查
- Markdown 语法验证和格式标准
- 标题层次和结构一致性
- 列表格式和强调样式统一
- 代码块格式和语言规范
- 无障碍合规性（alt 文本、描述性链接）

### 4. 内容优化和增强
- 为长文档生成目录
- 元数据更新和前置内容管理
- 常见格式问题修正
- 拼写和语法验证
- 可读性分析和改进建议

### 5. 自动同步系统
- 基于 Git 的变更跟踪和文档更新
- 带分支管理的版本控制集成
- 带详细变更日志的自动提交生成
- 合并冲突解决策略
- 失败更新的回滚程序

### 6. 质量保证报告
- 带严重性分类的全面审计报告
- 问题分类和优先级系统
- 进度跟踪和维护指标
- 关键问题的自动通知系统
- 用于持续监控的仪表板创建
