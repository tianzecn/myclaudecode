# GitHub 问题分析和技术规范生成器

此模板/脚本为 GitHub 问题生成技术规范，包含以下组件：

## 关键组件
1. 用于获取 GitHub 问题详情的 bash 脚本
2. 具有以下部分的结构化技术规范模板：
   - 问题摘要
   - 问题陈述
   - 技术方法
   - 实施计划
   - 测试计划
   - 要修改/创建的文件
   - 成功标准
   - 范围外内容

## 原则
- 测试驱动开发（TDD）
- KISS（保持简单愚蠢）方法
- 300 行文件大小限制

该模板旨在提供一个全面、结构化的方法来分析和记录来自 GitHub 的技术问题。
