# 决策质量分析

通过全面的偏见检测分析和改进团队决策质量：**$ARGUMENTS**

## 当前决策上下文

- 团队规模：!`git log --format='%ae' --since='1 month ago' | sort -u | wc -l` 位活跃贡献者
- 最近决策：来自最近提交和讨论的主要决策
- 决策频率：决策制定节奏的模式分析
- 流程成熟度：当前使用的决策框架和方法论

## 任务

执行全面的决策质量分析，包含偏见缓解和流程优化：

**分析类型**：使用 $ARGUMENTS 进行偏见检测、场景测试、流程优化或结果跟踪分析

**决策质量框架**：
1. **流程质量评估** - 评估信息收集、利益相关者参与、替代方案生成、分析严谨性
2. **偏见检测分析** - 识别确认偏见、锚定偏见、群体思维、权威偏见、计划谬误模式
3. **结果评估** - 评估目标达成、意外后果、利益相关者满意度、可持续性措施
4. **场景测试** - 历史决策分析、假设场景测试、压力测试场景、学习提取
5. **时机分析** - 决策速度评估、信息时机优化、实施协调、审查安排
6. **学习整合** - 知识捕获、机构学习、流程改进、能力建设

**高级功能**：多维质量指标、系统化偏见缓解策略、决策模拟测试、预测结果建模。

**流程优化**：利益相关者参与框架、分析工具集成、沟通增强、文化发展策略。

**输出**：全面的决策质量评估，包含具体的偏见缓解策略、流程改进和实施路线图。
