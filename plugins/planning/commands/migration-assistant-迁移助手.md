# 迁移助手

执行全面的系统迁移，包含规划、验证和回滚能力：**$ARGUMENTS**

## 当前迁移上下文

- 源系统：GitHub CLI 认证和 API 访问状态
- 目标系统：Linear MCP 服务器连接和权限
- 备份存储：可用存储空间和备份验证
- 迁移范围：数据量估算和复杂度评估

## 任务

执行系统化迁移流程，包含全面的安全措施和验证：

**迁移操作**：使用 $ARGUMENTS 指定迁移规划、分析、执行、验证或回滚操作

**迁移框架**：
1. **先决条件验证** - 验证 GitHub CLI 认证、确认 Linear MCP 连接、验证权限、确保备份存储
2. **迁移规划** - 评估数据量和复杂度、设计迁移策略、识别依赖、创建回滚计划
3. **风险分析** - 评估潜在故障点、评估数据完整性风险、识别系统依赖、规划应急措施
4. **执行管理** - 实施迁移阶段、监控进度和健康、优雅处理错误、维护审计跟踪
5. **验证流程** - 验证数据完整性、确认系统功能、测试用户工作流、验证性能指标
6. **回滚过程** - 实施安全回滚机制、恢复系统状态、验证恢复、沟通状态更新

**高级功能**：增量迁移支持、实时进度监控、自动健康检查、全面日志记录、紧急停止机制。

**安全措施**：多点备份、完整性验证、回滚测试、系统健康监控、利益相关者沟通。

**输出**：完整的迁移执行，包含进度跟踪、验证报告、回滚准备和迁移后优化建议。
