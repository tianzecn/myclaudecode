# 修复 TODOs

我将通过智能理解和跨会话的连续性系统性地查找并解决你代码库中的 TODO 注释。

参数：`$ARGUMENTS` - 要修复的文件、目录或特定 TODO 模式

## 会话智能

我将跨会话维护 TODO 解决进度：

**会话文件（在当前项目目录中）：**
- `fix-todos/plan.md` - 找到的所有 TODOs 和解决状态
- `fix-todos/state.json` - 当前进度和决策

**重要**：会话文件存储在当前项目目录的 `fix-todos` 文件夹中

**自动检测：**
- 如果会话存在：从上一个 TODO 恢复
- 如果没有会话：扫描并创建新计划
- 命令：`resume`、`status`、`new`

## 阶段 1：发现和分析

**强制性首要步骤：**
1. 检查当前工作目录中是否存在 `fix-todos` 目录
2. 如果目录存在，检查会话文件：
   - 查找 `fix-todos/state.json`
   - 查找 `fix-todos/plan.md`
   - 如果找到，从现有会话恢复
3. 如果没有目录或会话存在：
   - 扫描整个代码库的 TODOs
   - 创建分类计划
   - 初始化进度跟踪
4. 在开始前显示 TODO 摘要

我将查找并分类所有 TODOs：

**TODO 检测：**
- TODO、FIXME、HACK、XXX 标记
- 不同的优先级级别
- 上下文和复杂度评估
- 相关代码理解

**智能分类：**
- **快速修复**：简单验证、空值检查
- **功能**：缺失功能
- **重构**：代码改进
- **安全**：安全和验证需求
- **性能**：优化机会

## 阶段 2：解决规划

基于分析，我将创建一个解决计划：

**优先顺序：**
1. 安全关键的 TODOs
2. Bug 相关的 TODOs
3. 简单改进
4. 功能添加
5. 性能优化

我将把这个计划写入 `fix-todos/plan.md`，包含：
- 每个 TODO 的位置和内容
- 建议的解决方法
- 风险评估
- 实施顺序

## 阶段 3：智能解决

我将修复匹配你代码模式的 TODOs：

**模式检测：**
- 在你的代码中找到类似实现
- 匹配你的错误处理风格
- 使用你的验证模式
- 遵循你的命名约定

**解决策略：**
- 错误处理 → 你的 try/catch 模式
- 验证 → 你的输入检查风格
- 性能 → 你的优化方法
- 安全 → 你的安全模式

## 阶段 4：增量实施

我将系统性地解决 TODOs：

**执行流程：**
1. 创建 git 检查点
2. 通过上下文理解修复 TODO
3. 验证功能保持不变
4. 用完成情况更新计划
5. 移至下一个 TODO

**进度跟踪：**
- 在计划中标记每个 TODO 为已解决
- 用决策更新状态文件
- 创建有意义的提交

## 阶段 5：验证

每次解决后：
- 运行相关测试
- 检查回归
- 验证集成点
- 确保代码质量

## 上下文连续性

**会话恢复：**
当你返回并运行 `/fix-todos` 或 `/fix-todos resume` 时：
- 加载现有计划和进度
- 显示完成统计
- 从上一个 TODO 继续
- 维护所有解决决策

**进度示例：**
```
恢复 TODO 修复
├── 总 TODOs：47
├── 已解决：23（49%）
├── 当前：src/api/auth.js:42
└── 下一个：src/utils/validation.js:15

继续解决...
```

## 实用示例

**开始修复：**
```
/fix-todos                    # 修复所有 TODOs
/fix-todos src/              # 专注于目录
/fix-todos "security"        # 修复安全 TODOs
```

**会话控制：**
```
/fix-todos resume    # 继续现有会话
/fix-todos status    # 检查进度
/fix-todos new       # 重新开始
```

## 安全保证

**保护措施：**
- 变更前的 Git 检查点
- 增量提交
- 功能验证
- 没有实现不删除 TODO

**重要**：我永远不会：
- 在不修复的情况下删除 TODOs
- 破坏现有功能
- 添加 AI 归属
- 在不理解上下文的情况下实现

## 命令建议

解决关键 TODOs 后：
- `/test` - 确保修复正常工作
- `/commit` - 保存 TODO 解决

## 我实际将做什么

1. **全面扫描** - 找到所有带上下文的 TODOs
2. **战略规划** - 按优先级和风险排序
3. **智能解决** - 匹配你的模式
4. **细致跟踪** - 完美的会话连续性
5. **持续验证** - 确保维持质量

我将在会话之间保持完全的连续性，始终从我们离开的地方恢复，并完整保留先前解决方案的上下文。
