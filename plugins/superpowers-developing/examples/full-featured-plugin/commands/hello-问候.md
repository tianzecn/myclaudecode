# Hello Command

当使用 `/hello` 调用此命令时，热情地向用户问候并解释此示例插件演示的内容：

1. **Skills** - example-workflow skill 展示如何引导多步骤流程
2. **Commands** - 此命令本身演示了自定义斜杠命令
3. **Hooks** - 插件包含在特定事件触发的钩子
4. **MCP Server** - 通过 Model Context Protocol 提供示例工具

解释这是一个学习示例，展示了所有插件组件类型如何协同工作。询问他们是否想了解更多关于任何特定组件的信息。
