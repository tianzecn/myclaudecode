# 游戏资源管线与处理系统

构建全面的游戏资源处理管线：$ARGUMENTS

## 当前资源环境

- 项目资源：!`find . -name "*.png" -o -name "*.fbx" -o -name "*.wav" -o -name "*.mp3" | wc -l` 个总资源
- 资源大小：!`du -sh Assets/ 2>/dev/null || du -sh assets/ 2>/dev/null || echo "No assets folder found"`
- 构建工具：!`which blender`; !`which ffmpeg`; !`which imagemagick`
- 平台目标：@ProjectSettings/ProjectSettings.asset 或从构建配置检测
- 版本控制：!`git lfs ls-files | wc -l` 个 LFS 追踪文件

## 任务

创建自动化资源处理管线，包含优化、验证、平台特定交付和游戏开发工作流的实时监控。

## 资源管线组件

### 1. 资源导入与验证
- 自动化资源格式验证和标准化
- 纹理分辨率和模型复杂度的质量保证检查
- 资源命名约定强制执行
- 元数据提取和标签系统
- 源资源备份和版本控制集成

### 2. 多平台优化
- 平台特定纹理压缩（ASTC、DXT 等）
- 模型 LOD 生成和优化
- 音频格式转换和压缩
- 目标平台的着色器变体编译
- 每个平台的内存预算验证

### 3. 构建集成
- 构建管线期间的自动化资源处理
- 仅对修改的资源进行增量处理
- 资源包生成和打包
- 依赖关系追踪和解析
- 构建时资源验证和错误报告

### 4. 质量保证
- 纹理变更的视觉差异对比
- 模型几何验证和优化
- 音频质量和压缩比分析
- 新资源的性能影响评估
- 资源变更的自动化回归测试

## 处理工作流

### 纹理处理管线
- 导入验证和格式标准化
- 自动 mipmap 生成和优化
- 带质量设置的平台特定压缩
- 内存使用估算和优化
- 与精灵图集和纹理流式传输的集成

### 3D 模型处理管线
- 导入验证和网格优化
- 可配置缩减比例的自动 LOD 生成
- 骨骼和动画优化
- 纹理坐标验证和优化
- 碰撞网格生成和验证

### 音频处理管线
- 格式标准化和质量验证
- 带比特率优化的平台特定压缩
- 音频资源标签和分类
- 流式传输与内存加载的建议
- 音频遮蔽和空间化准备

### 动画处理管线
- 动画片段优化和压缩
- 关键帧缩减和平滑
- 骨骼层次验证和优化
- 动画事件验证和文档
- 运行时性能影响分析

4. **文档与指南**
